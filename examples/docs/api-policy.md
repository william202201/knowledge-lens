# API policy / API 使用规范

## Rate limits / 速率限制
当 API 超过速率限制返回 429 时，客户端应使用指数退避并添加随机抖动；优先遵守 Retry-After 响应头。最多重试三次，不要立即无限重试。此规则是本项目虚构公司的示例规范，不代表任何供应商的正式条款。

## Credentials / 密钥管理
API Key 只允许保存在服务端环境变量中，不能写入浏览器、日志、Git 仓库或截图。轮换密钥后应重启服务，确认新密钥生效。

## Request timeout / 超时
内部 HTTP 请求超时设为 30 秒。不可幂等的写入请求发生超时时，先检查执行状态，再决定是否重试。
